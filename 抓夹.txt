## 再检查 effort

```bash
ros2 topic echo /joint_states
```

这次重点不要只看机械臂完全静止的一瞬间。

让机械臂执行一次归零或小角度运动：

```bash
ros2 action send_goal \
/arm_controller/follow_joint_trajectory \
control_msgs/action/FollowJointTrajectory \
"{trajectory: {
  joint_names: [Joint1, Joint2, Joint3, Joint4, Joint5, Joint6],
  points: [{
    positions: [0.1, -0.1, 0.1, 0.05, -0.05, 0.05],
    time_from_start: {sec: 2, nanosec: 0}
  }]
}}" \
--feedback
```

同时另一个终端：

```bash
ros2 topic echo /joint_states
```

现在重点观察：

```text
effort:
```

是否已经从：

```text
0
0
0
0
0
0
```

变成随运动变化的有限值。

如果是，那么：

```text
Gazebo position PID
→ joint torque
→ /joint_states.effort
```

这一关就真正打通了。
